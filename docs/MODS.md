# Mod List

Mods that are in Modded Bridge, this excludes library mods and modpack
management mods.

Mostly based on [Adrenaline](https://skywardmc.org/adrenaline) and
[Additive](https://skywardmc.org/additive).

## Optional Mods

Mods that is included in the pack but not install/enable by default. Be sure to
also install/enable any mod dependencies if they were not by default. If you run
a multiplayer server, you will need to also make sure to install/enable them on
both the server and client if recommended.
