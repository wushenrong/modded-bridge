# Configuration Changes

Here are additional default configuration changes applied on top of
[Adrenaline](https://skywardmc.org/adrenaline/config-changes/) and
[Additive](https://skywardmc.org/additive/config-changes/).

## Changed Settings

-   [Squat Growth](https://modrinth.com/project/b5JMdB5V)

    -   Disable squat growth for the following plants:

        - Bush
        - Crimson Root
        - Dripleaf
        - Fern
        - Firefly Bush
        - Pink Petal
        - Rose Bush
        - Short Dry Grass
        - Sunflower
        - Wild Flower

## Additions from Fabulously Optimized

See <https://wiki.download.fo/changed-options> for additional options you might
want to apply.

-   Include the following mods

    - [Better Mount HUD](https://modrinth.com/project/kqJFAPU9)
    - [Fabrishot](https://modrinth.com/project/3qsfQtE9)
    - [Reese's Sodium Options](https://modrinth.com/project/Bh37bMuy)
    - [Sodium Shadowy Path Blocks](https://modrinth.com/project/EIa1eiMm)

-   Add [Translations for Sodium](https://modrinth.com/project/yfDziwn1) and
    [Continuity](https://modrinth.com/project/1IjD5062) to the resource pack
    list.

-   Set `telemetryOptInExtra` to `false`.

    Disable additional telemetry, in case this gets enabled in a later release.

-   Set `advancedItemTooltips` to `true`.

    Shows addition information when hovering over items in the inventory.

-   Adds settings for Fabrishot.

## Recommended Keybinds

Below is a list of recommended keybinds to change. Modded Bridge used to change
the default keybinds and applied recommendations from Fabulously Optimized, but
they were removed to keep the configuration changes to the minimum.

- Iris: Reload Shaders
- Iris: Shaderpack Selection Screen
- Iris: Toggle Shaders
- Movement: Toggle Auto Jump
- OptiGUI: Copy inspection to clipboard
- Render Scale: Open Config
- Simple Voice Chat: Mute Microphone
- Zoomify: Secondary zoom
- Zoomify: Zoom
